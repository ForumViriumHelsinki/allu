# Forum Virium Helsinki working documents

Everything in `docs/fvh/` is **Forum Virium Helsinki's own material**, not a
description of Allu as it exists. It is kept in this repository because the work
is grounded in this codebase and agents working here need the context, but it is
scoped to its own directory so the distinction stays visible.

The rest of `docs/` describes the platform as built and is, in principle,
offerable upstream to [City-of-Helsinki/allu](https://github.com/City-of-Helsinki/allu).
This directory is not.

| Document | What it is |
| --- | --- |
| [Excavation timeline service](excavation-timeline-service.md) | Design guide for an FVH-built map + timeline service over excavation data. Describes a service that does not exist yet. |
| [Upstream proposals](upstream-proposals.md) | Four proposed changes to Allu itself, drafted while designing the above. Working draft — the intended endpoint is one GitHub issue per proposal on the upstream repo, not this file. |

## Provenance

This repository is a fork: `origin` is `ForumViriumHelsinki/allu`, `upstream` is
`City-of-Helsinki/allu`, which is actively developed by Gofore for the city.
Nothing in this directory has been proposed to or agreed with upstream.
